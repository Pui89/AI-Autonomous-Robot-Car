# Autonomous Driving Research — Simulation Only

Status: research plan; no autonomous-driving capability is claimed.

## Candidate tools
CARLA for driving scenarios; SUMO for traffic flow; ROS 2 and Gazebo for simulated robotics. Before adoption, check exact licence, version, download size, hardware needs and billing exposure. Do not automatically install large tools or assets.

## Scenarios
Day/night, poor visibility, rain, standing water, pedestrians, cyclists, occlusion, roadworks, lane ambiguity, sensor dropout, delay, noise, disagreement, GPS loss and unexpected objects.

## Metrics
Scenario count, missed hazards, false alerts, precision/recall when labels support them, stale-data rejection, uncertainty behavior and reproducibility. Report denominators and limitations.

Simulation only. No road deployment, vehicle connection or actuator control.
