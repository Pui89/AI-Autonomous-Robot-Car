# AI and Safety Benchmarks

Status: protocol only; no performance results claimed.

Each benchmark record must include ID, purpose, repository commit, shared-core version, data provenance/licence, scenario count, baseline, configuration, metrics, uncertainty, failures, limitations and reproduction steps.

Initial software metrics: contract validation, rejection of invalid/stale/missing/conflicting inputs, missed hazards and false alerts on labeled synthetic scenarios, prohibited-proposal rejection and deterministic replay.

Do not report accuracy without class balance and sample size. A passing software benchmark does not establish physical safety or road performance.
